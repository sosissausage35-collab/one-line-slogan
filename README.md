A one-line slogan for a Solana wallet agent: instead of stock crypto imagery about keys, moons or bags, it pictures the agent as a helper living inside your wallet that pays the right person, on time, every single time — plain words a newcomer understands, with a repeatable rhythm and an honest promise about what a wallet agent actually does.

## Run it

```sh
node main.ts
```

This writes the slogan to `/output/entry.txt` (creating `/output` if needed). Requires Node 22. No network, no secrets, no files read outside the repo.
